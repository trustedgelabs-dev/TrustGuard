# Privacy Policy

**Last updated:** April 2026
**Developer:** TrustEdge Labs

---

## Summary

TrustGuard is a local-first privacy tool. It does not collect, store, or transmit any personal data.

---

## Data Collection

TrustGuard collects **no data**. Specifically:

- No account or registration is required.
- No analytics SDK is included.
- No crash reporting service is active by default.
- No advertising network is integrated.
- No usage statistics are sent to any server.

---

## Data Processed Locally

TrustGuard processes the following data **only on your device**:

| Data | Purpose | Leaves Device? |
|---|---|---|
| List of installed apps | Permission risk analysis | No |
| Network connections | Local firewall / DNS filtering | No |
| Wi-Fi network details | Security analysis | No |
| App usage time | Screen time / parental controls | No |
| Files on device | File recovery scanner | No |
| Vault contents | Encrypted local storage | No |

---

## Internet Access

TrustGuard requests the `INTERNET` permission solely to operate the local VPN tunnel for DNS filtering. TrustGuard does not send personal data, analytics, telemetry, or usage history to TrustEdge Labs servers. DNS filtering may forward DNS queries to the configured upstream DNS resolver (e.g. Cloudflare 1.1.1.1) as required for normal internet resolution.

---

## Third-Party Services

TrustGuard does not integrate any third-party analytics, advertising, or crash reporting services.

---

## Children

TrustGuard includes parental control features that are controlled and visible to the device owner. These features do not covertly monitor children — all restrictions and monitoring are accessible through the app settings.
