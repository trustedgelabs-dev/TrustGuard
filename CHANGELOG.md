## v3.0.0 — 2026-04-11

### Initial open-source release

- Full source code published under GPLv3
- All features are free — no subscriptions, no ads, no accounts
- Removed Google Play Billing integration (stub replaced with always-free)

### Features included in this release

- App Permission Analyzer
- Local VPN-based DNS Ad/Tracker Blocker
- Firewall (per-app internet access control)
- Wi-Fi Security Checker
- Adware & Bloatware Detection
- Device Hygiene Checks (root, USB debug, unknown sources)
- Local Network Activity Monitor
- Privacy Tools (app vault, fake identity, app locking)
- File Recovery (MediaStore-based)
- System Optimization (battery, storage)
- Parental Controls (screen time, app limits, content filtering)
- Family Shield (multi-profile support)
